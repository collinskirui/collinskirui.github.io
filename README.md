# Portfolio

Add content by creating a Markdown file in one of these folders:
- `_posts/YYYY-MM-DD-title.md`  → blog
- `_projects/name.md`           → projects
- `_assignments/name.md`        → coursework

Every file starts with:
---
title: My title
topic: security        # groups it on the Topics page
summary: One line shown on lists
---
Then write in Markdown. Edit `_config.yml` for your name, links and menu.
