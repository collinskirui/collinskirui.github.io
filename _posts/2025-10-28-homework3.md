## What is RSA?

RSA is an asymmetric encryption algorithm, which means it uses two keys:

* Public Key (e, n) → used to encrypt messages 

* Private Key (d, n) → used to decrypt messages

- The idea: Anyone can encrypt a message for you using your public key, but only you, holding the private key, can decrypt it. This ensures confidentiality.


## How RSA keys are generated
1. Pick two prime numbers: p and q

   Example: p=29, q=37 

2. Compute n=p⋅q

      29*37 = 1073

3. Compute Euler’s totient: 
       ϕ(n) = (p−1)(q−1) = 28⋅36=1008

4. Choose an encryption exponent e:
         1<e<ϕ(n),gcd(e,ϕ(n)) = 1

    Example: e = 7
 
5. Compute the decryption exponent d:
        d⋅7 ≡ 1 mod  ϕ(n)
       7⋅d ≡ 1 mod 1008 ⟹ d = 865

Keys:
Public: (e=7, n=1073)
Private: (d=865, n=1073)


 
| Parameter | Value |
| --------- | ----- |
| p         | 29    |
| q         | 37    |
| n         | 1073  |
| φ(n)      | 1008  |
| e         | 7     |
| d         | 865   |

## Encryption 

For a message M where 0 ≤ M < n:

$$
C = M^e \bmod n
$$

M = numeric value of letter (a=0, b=1, …, z=25)  
C = ciphertext


| Letter | M  | C = M⁷ mod 1073 |
| ------ | -- | --------------- |
| l      | 11 | 507             |
| o      | 14 | 146             |
| r      | 17 | 802             |
| e      | 4  | 163             |
| m      | 12 | 624             |
| i      | 8  | 71              |

Ciphertext (first 10 letters):

[507, 146, 802, 163, 624, 71, ...]


## Decryption

To decrypt ciphertext C:

$$
M = C^d \bmod n
$$

C = ciphertext  
M = numeric value of original letter


| C   | Decrypted M | Letter |
| --- | ----------- | ------ |
| 507 | 11          | l      |
| 146 | 14          | o      |
| 802 | 17          | r      |
| 163 | 4           | e      |
| 624 | 12          | m      |

Decryption formula:
           
$$
M = C^d \bmod n
$$

Using modular exponentiation step by step (binary method) to simplify:

C = 507 → M = 11 → l

C = 802 → M = 14 → o

C = 974 → M = 17 → r

C = 163 → M = 4  → e

C = 624 → M = 12 → m
