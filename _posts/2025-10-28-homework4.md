[Law of Large Numbers (LLN)](https://www.probabilitycourse.com/chapter7/7_1_1_law_of_large_numbers.php) is a fundamental principle in probability theory that asserts that as a random experiment is repeated numerous times, the average of the outcomes will converge towards the expected value or true predicted average of those outcomes.

```For repeated, independent trials, the empirical mean (or relative frequency) stabilizes near the theoretical expectation as the number of trials increases.```

## Approach

Let X₁, X₂, …, Xₙ be independent and identically distributed random variables with expectation E[X].  
The sample mean is defined as

$$
f(n) = \frac{X_1 + X_2 + \cdots + X_n}{n}
$$

According to the Law of Large Numbers

$$
f(n) \to E[X] \quad \text{as } n \to \infty
$$

In this case, we model Xᵢ as Bernoulli trials — i.e., success = 1, failure = 0 — with success probability p = 0.3.  
Hence E[X] = p.  
As n grows, the relative frequency of successes (our running mean) converges toward 0.3.

## Simulation Testing
We simulate several independent trajectories, each consisting of repeated Bernoulli trials with probability \( p \).

| Parameter | Description | Value |
| :-------------------------- | :------------------------------------ | :----: |
| \( p \) | Success probability | 0.3 |
| \( n \) | Number of trials | 600 |
| \( m \) | Number of runs | 10 |

Each trajectory shows the running mean f(n), illustrating how the empirical mean converges to \(p\).

### Illustrative Table

Representative results from typical runs show that as n increases, the estimates cluster tightly around p.

| n     | f(n) — Run 1 | f(n) — Run 2 | f(n) — Run 3 | Target (p) |
| ----- | ------------ | ------------ | ------------ | ----------- |
| 40    | 0.28         | 0.32         | 0.25         | 0.30        |
| 120   | 0.31         | 0.29         | 0.30         | 0.30        |
| 300   | 0.30         | 0.32         | 0.28         | 0.30        |
| 600   | 0.30         | 0.31         | 0.29         | 0.30        |
| 1000  | 0.30         | 0.30         | 0.30         | 0.30        |

### Interpretation

- At the beginning of each trajectory, f(n) fluctuates randomly.  
- As the number of trials increases, these fluctuations decrease, and all trajectories cluster close to the expected value (p = 0.3).  

This illustrate the essence of the **Law of Large Numbers**: randomness cancels out over many repetitions.

---

## Conclusion

The simulation and visualizations show that with many independent trials:

- Random results become predictable in their average.  
- The sample mean stabilizes near the true probability \(p\).  
- Variability decreases as \(n\) increases.

Thus, the **Law of Large Numbers** guarantees that empirical averages are trustworthy estimates of theoretical expectations in the long run.

/* avoid {{ }} that Liquid could touch */
function runLLN() {
  const p   = parseFloat(document.getElementById('pVal').value);
  const n   = parseInt(document.getElementById('nVal').value);
  const m   = parseInt(document.getElementById('mVal').value);
  const traces = [];

  for (let i = 0; i < m; i++) {
    const trials = Array.from({length: n}, () => Math.random() < p ? 1 : 0);
    const run = [];
    let sum  = 0;
    for (let k = 0; k < n; k++) {
      sum += trials[k];
      run.push(sum / (k + 1));
    }
    traces.push({
      y: run,
      type: 'scatter',
      mode: 'lines',
      name: 'Run ' + (i + 1),
      line: {width: 2},
      opacity: 0.8
    });
  }

  traces.push({
    y: Array(n).fill(p),
    type: 'scatter',
    mode: 'lines',
    name: 'True mean (p = ' + p + ')',
    line: {dash: 'dash', color: 'black', width: 2}
  });

  Plotly.newPlot('llnPlot', traces, {
    title: 'Law of Large Numbers demonstration',
    xaxis: {title: 'Number of trials'},
    yaxis: {title: 'Running mean', range: [0, 1]},
    plot_bgcolor: '#fff',
    paper_bgcolor: '#fff'
  }, {responsive: true});
}

document.getElementById('runBtn').addEventListener('click', runLLN);
window.addEventListener('load', runLLN);
</script>

const pHist   = 0.3;
const nHist   = 600;
const runsHist = 1000;
const means   = [];

for (let i = 0; i < runsHist; i++) {
  let sum = 0;
  for (let k = 0; k < nHist; k++) sum += (Math.random() < pHist ? 1 : 0);
  means.push(sum / nHist);
}
