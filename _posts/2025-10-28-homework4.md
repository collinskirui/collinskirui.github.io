[Law of Large Numbers (LLN)](https://www.geeksforgeeks.org/data-science/what-is-dataset/) is a structured collection of related data, usually organized in rows and columns, representing information about a specific category or domain.

For repeated, independent trials, the empirical mean (or relative frequency) stabilizes near the theoretical expectation as the number of trials increases.

## Approach

Let X₁, X₂, …, Xₙ be independent and identically distributed random variables with expectation E[X].  
The sample mean is defined as:

$$
f(n) = \frac{X_1 + X_2 + \cdots + X_n}{n}
$$

According to the Law of Large Numbers:

$$
f(n) \to E[X] \quad \text{as } n \to \infty
$$

In this case, we model Xᵢ as Bernoulli trials — i.e., success = 1, failure = 0 — with success probability p = 0.6.  
Hence E[X] = p.  
As n grows, the relative frequency of successes (our running mean) converges toward 0.6.

function runLLN() {
  const p = parseFloat(document.getElementById('pVal').value);
  const n = parseInt(document.getElementById('nVal').value);
  const m = parseInt(document.getElementById('mVal').value);
  let traces = [];

  for (let i = 0; i < m; i++) {
    let trials = Array.from({length: n}, () => Math.random() < p ? 1 : 0);
    let runningMean = trials.map((_, j) =>
      trials.slice(0, j + 1).reduce((a, b) => a + b, 0) / (j + 1)
    );
    traces.push({
      y: runningMean,
      type: 'scatter',
      mode: 'lines',
      name: 'Run ' + (i + 1),
      opacity: 0.7
    });
  }

  // True mean line
  traces.push({
    y: Array(n).fill(p),
    type: 'scatter',
    mode: 'lines',
    name: 'True Mean p = ' + p,
    line: {dash: 'dash', color: 'black'}
  });

  Plotly.newPlot('llnPlot', traces, {
    title: 'Law of Large Numbers Demonstration',
    xaxis: {title: 'Number of Trials (n)'},
    yaxis: {title: 'Running Mean'},
    legend: {orientation: 'h'}
  });
}

### Interpretation

At the beginning of each trajectory, \(f(n)\) fluctuates randomly.  
As the number of trials increases, these fluctuations decrease, and all trajectories cluster close to the expected value \(p = 0.6\).  

This illustrates the **Law of Large Numbers (LLN)**: empirical averages become reliable estimates of the true mean when the sample size is large.

- At small \(n\), the running averages vary greatly between runs.  
- As \(n\) grows, all lines approach the true mean and fluctuations shrink.  
- The histogram confirms that large-sample averages concentrate around the expected value.

This behavior is the essence of the **Law of Large Numbers**: randomness cancels out over many repetitions.

---

## Conclusion

The simulation and visualizations show that with many independent trials:

- Random results become predictable in their average.  
- The sample mean stabilizes near the true probability \(p\).  
- Variability decreases as \(n\) increases.

Thus, the **Law of Large Numbers** guarantees that empirical averages are trustworthy estimates of theoretical expectations in the long run.
