[Law of Large Numbers (LLN)](https://www.probabilitycourse.com/chapter7/7_1_1_law_of_large_numbers.php) is a fundamental principle in probability theory that asserts that as a random experiment is repeated numerous times, the average of the outcomes will converge towards the expected value or true predicted average of those outcomes.

```For repeated, independent trials, the empirical mean (or relative frequency) stabilizes near the theoretical expectation as the number of trials increases.```

## Approach

Let X₁, X₂, …, Xₙ be independent and identically distributed random variables with expectation E[X].  
The sample mean is defined as

$$
f(n) = \frac{X_1 + X_2 + \cdots + X_n}{n}
$$

According to the Law of Large Numbers

$$
f(n) \to E[X] \quad \text{as } n \to \infty
$$

In this case, we model Xᵢ as Bernoulli trials — i.e., success = 1, failure = 0 — with success probability p = 0.3.  
Hence E[X] = p.  
As n grows, the relative frequency of successes (our running mean) converges toward 0.3.

## Simulation Testing
We simulate several independent trajectories, each consisting of repeated Bernoulli trials with probability \( p \).

| Parameter | Description | Value |
| :-------------------------- | :------------------------------------ | :----: |
| \( p \) | Success probability | 0.3 |
| \( n \) | Number of trials | 600 |
| \( m \) | Number of runs | 10 |

Each trajectory shows the running mean f(n), illustrating how the empirical mean converges to \(p\).

<script>
function runLLN() {
  const p = parseFloat(document.getElementById('pVal').value);
  const n = parseInt(document.getElementById('nVal').value);
  const m = parseInt(document.getElementById('mVal').value);

  let traces = [];
  for (let i = 0; i < m; i++) {
    const trials = Array.from({length: n}, () => Math.random() < p ? 1 : 0);
    const runningMean = trials.map((_, j) =>
      trials.slice(0, j + 1).reduce((a,b)=>a+b,0)/(j+1)
    );
    traces.push({
      y: runningMean,
      type: 'scatter',
      mode: 'lines',
      name: 'Run ' + (i+1),
      line: {width:2},
      opacity:0.8
    });
  }

  // True mean
  traces.push({
    y: Array(n).fill(p),
    type:'scatter',
    mode:'lines',
    name:'True Mean (p=' + p + ')',
    line: {dash:'dash', color:'black', width:2}
  });

  const layout = {
    title:'Law of Large Numbers Demonstration',
    xaxis:{title:'Number of Trials', gridcolor:'#eee'},
    yaxis:{title:'Running Mean', gridcolor:'#eee', range:[0,1]},
    plot_bgcolor:'#fff',
    paper_bgcolor:'#fff'
  };

  Plotly.newPlot('llnPlot', traces, layout, {responsive:true});
}

document.getElementById('runBtn').addEventListener('click', runLLN);
window.addEventListener('load', runLLN);
</script>

// Parameters
const p = 0.3, n = 600, runs = 1000;

let finalMeans = [];
for (let i = 0; i < runs; i++) {
  const trials = Array.from({length: n}, () => Math.random() < p ? 1 : 0);
  finalMeans.push(trials.reduce((a,b)=>a+b,0)/n);
}

Plotly.newPlot('histLLN', [{
