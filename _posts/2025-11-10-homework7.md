#  Random Walk 

In this assignment we extend the **Law of Large Numbers** and **Random Walk intuition** by imagining a server that needs to be ugraded against multiple attacker(s) each week.

## 1. Problem setup

A server receives weekly updates for $$n$$ weeks. Each week:

- there are $$m$$ independent attackers,
- each attacker succeeds with probability $$p$$,
- if **no attacker** succeeds we record **+1**,
- if **any attacker** succeeds we record **−1**.

Each week is therefore a step in a **biased random walk**.

---
## 2. Weekly probability

The probability that *no* attacker succeeds in a week is:

$$ (1 - p)^m $$

So the weekly breach probability is:

$$ r = 1 - (1 - p)^m $$

Each weekly outcome \(X_i\) is:

$$
X_i = \begin{cases}
+1 & \text{with probability } 1 - r\\[1mm]
-1 & \text{with probability } r
\end{cases}
$$

---

## 3. Cumulative score and distribution

After \(n\) weeks the cumulative score is:

$$ S_n $$ = $$ \sum_{i=1}^n X_i $$

Let \(B\) be the number of breached weeks:

$$ B \sim \mathrm{Binomial}(n, r), \qquad S_n = n - 2B $$

Possible values of \(S_n\):

$$ S_n \in \{-n, -n+2, \ldots, n-2, n\} $$

PMF:

$$ P(S_n = n - 2b) = \binom{n}{b} r^b (1-r)^{n-b}, \quad b=0,\ldots,n $$

Expected value and variance:

$$ E[S_n] = n(1-2r), \quad \mathrm{Var}(S_n) = 4 n r(1-r) $$

---
**Simulation parameters**

| Symbol | Description | Example values |
|---------|-------------|----------------|
| \(n\) | Number of weeks | 20, 50, 100 |
| \(m\) | Number of attackers operating simultaneously | 1–10 |
| \(p\) | Success probability of a single attacker per week. | 0.1–0.5 |
| \(r\) | Effective breach probability (combined of all attackers). | $$ r = 1 - (1 - p)^m $$ |
| \(q\) | Probability of remaining secure that week. | $$ q = (1 - p)^m $$ |
| trajectories | Simulated runs | 100–1000 |

**Probability derivation**

For \(m\) attackers, each success prob \(p\):

$$
q = (1 - p)^m, \quad p' = 1 - q
$$

**Example:**

| m | p | q | p′ (breach) |
|---|---|---|-------------|
| 1 | 0.3 | 0.7 | 0.3 |
| 2 | 0.3 | 0.49 | 0.51 |
| 5 | 0.3 | 0.168 | 0.832 |

<script>
function rng(seed){return new Math.seedrandom(seed||Date.now());}
function comb(n,k){if(k<0||k>n)return 0;let r=1;for(let i=1;i<=k;i++)r=r*(n+1-i)/i;return r;}
function simulate(n,r,trajs,seed){
  const gen=rng(seed);
  const xs=Array.from({length:n+1},(_,i)=>i);
  let lines=[];
  for(let t=0;t<trajs;t++){
    let s=0,arr=[0];
    for(let i=0;i<n;i++){s+=(gen()<r?-1:1);arr.push(s);}
    lines.push({x:xs,y:arr,mode:"lines",line:{color:"rgba(120,210,255,0.25)",width:1.4},hoverinfo:"none"});
  }
  const mean=xs.map(i=>i*(1-2*r));
  lines.push({x:xs,y:mean,mode:"lines",line:{dash:"dot",color:"#ff8c66",width:3}});
  Plotly.newPlot(seed+"-traj",lines,{
    paper_bgcolor:"#101a27",plot_bgcolor:"#101a27",
    margin:{l:60,r:20,t:10,b:40},
    xaxis:{title:"Weeks",gridcolor:"rgba(255,255,255,0.1)"},
    yaxis:{title:"Score",gridcolor:"rgba(255,255,255,0.1)"}
  });
}
function hist(n,r,sim,seed){
  const gen=rng(seed);
  const count={};
  for(let i=0;i<sim;i++){
    let b=0;for(let j=0;j<n;j++)if(gen()<r)b++;
    const s=n-2*b;count[s]=(count[s]||0)+1;
  }
  const keys=Object.keys(count).map(Number).sort((a,b)=>a-b);
  const emp=keys.map(k=>count[k]/sim);
  const theo=keys.map(s=>{
    const b=(n-s)/2;if(b<0||b>n||b%1!==0)return 0;
    return comb(n,b)*Math.pow(r,b)*Math.pow(1-r,n-b);
  });
  Plotly.newPlot(seed+"-hist",[
    {x:keys,y:emp,type:"bar",marker:{color:"rgba(110,200,250,0.8)"}},
    {x:keys,y:theo,mode:"lines",line:{color:"#ff9966",width:2}}
  ],{
    paper_bgcolor:"#101a27",plot_bgcolor:"#101a27",
    margin:{l:60,r:20,t:10,b:40},
    xaxis:{title:"Final Score",gridcolor:"rgba(255,255,255,0.1)"},
    yaxis:{title:"Probability",gridcolor:"rgba(255,255,255,0.1)"}
  });
}
function run(){
  const n=parseInt(document.getElementById("n").value)||20;
  const t=parseInt(document.getElementById("traj").value)||60;
  const s=parseInt(document.getElementById("nsim").value)||10000;
  const cases=[
    ["secure",0.05],
    ["balanced",0.5],
    ["single",0.3],
    ["multi",0.832],
    ["breach",0.998]
  ];
  cases.forEach(([id,r])=>{
    simulate(n,r,t,id);
    hist(n,r,s,id);
    document.getElementById(id+"-stats").innerText=`r=${r.toFixed(3)}, E[S_n]=${(n*(1-2*r)).toFixed(2)}`;
  });
}
document.getElementById("run").onclick=run;
window.onload=run;
</script>
